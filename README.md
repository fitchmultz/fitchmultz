# Mitch Fultz

I build open-source tools that help AI coding agents browse the web, delegate work, and keep going across long tasks. Most extend [Pi](https://github.com/earendil-works/pi/tree/main/packages/coding-agent), a coding agent that runs in your terminal.

## Start here

Start with [**Fitch Kit**](https://github.com/fitchmultz/pi-fitch-kit) for my Pi setup, installation instructions, and a guide to how the tools work together.

## Featured work

- [**Subagents**](https://github.com/fitchmultz/pi-subagents): delegate to specialists, run parallel reviews, and keep work going in the background.
- [**MCP Adapter**](https://github.com/fitchmultz/pi-mcp-adapter): connect Pi to external tools and services, discovering tools as needed instead of loading every definition upfront.
- [**Browser Native**](https://github.com/fitchmultz/pi-agent-browser-native): browse websites, test user flows, and capture screenshots without leaving the coding session.
- [**Posthorse**](https://github.com/fitchmultz/pi-posthorse): continue long tasks in fresh model context, with notes and searchable session history. **Requires [my Pi fork](https://github.com/fitchmultz/pi).**
- [**Cursor SDK**](https://github.com/fitchmultz/pi-cursor-sdk): run Cursor's agent loop inside Pi, with native model selection and tool access.

Also: [Codex Goal](https://github.com/fitchmultz/pi-codex-goal) for long-running objectives, and [Oracle](https://github.com/fitchmultz/pi-oracle) for background second opinions from ChatGPT or Grok. Oracle is an **experimental public beta**.

## Other work

- [**CueLoop**](https://github.com/fitchmultz/cueloop): queue and track coding-agent tasks, evidence, and handoffs.
- [**Spartan Scraper**](https://github.com/fitchmultz/spartan-scraper): scrape, crawl, and research websites through a UI, CLI, or API.
- [**agent-eval**](https://github.com/fitchmultz/agent-eval): compare Codex, Claude Code, Pi, and opencode session transcripts.
- [**Cloop**](https://github.com/fitchmultz/cloop#how-it-works): local tasks and searchable knowledge, with a web UI and CLI.
- [**AI Control Plane**](https://github.com/fitchmultz/ai-control-plane): a reference implementation for AI governance, not a managed production service.
