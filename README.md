# Mitch Fultz

I build and maintain open-source tools for AI coding-agent workflows: browser automation, model integrations, delegation, and long-running tasks. Most extend [Pi](https://github.com/earendil-works/pi/tree/main/packages/coding-agent), a coding agent that runs in your terminal.

## Start here

Start with [**Fitch Kit**](https://github.com/fitchmultz/pi-fitch-kit) for my Pi setup, installation instructions, and a guide to how the tools work together.

## Featured tools

- [**Cursor SDK**](https://github.com/fitchmultz/pi-cursor-sdk): run Cursor's SDK agent loop inside Pi, with Pi model selection and an optional local Pi-tool bridge.
- [**Browser Native**](https://github.com/fitchmultz/pi-agent-browser-native): automate browsers, test web flows, and capture screenshots from Pi using `agent-browser`.
- [**Codex Goal**](https://github.com/fitchmultz/pi-codex-goal): persistent goal tracking and guarded continuation for long-running Pi tasks.
- [**Oracle**](https://github.com/fitchmultz/pi-oracle): send project context to ChatGPT or Grok web apps for background second opinions. **Experimental public beta.**

## Workflow infrastructure

- [**Subagents**](https://github.com/fitchmultz/pi-subagents): delegate to specialists, run parallel reviews, and keep work going in the background.
- [**MCP Adapter**](https://github.com/fitchmultz/pi-mcp-adapter): connect Pi to external tools and services, discovering tools as needed instead of loading every definition upfront.
- [**Posthorse**](https://github.com/fitchmultz/pi-posthorse): summary-free context rollover, durable notes, and searchable session history. Supports official Pi 1.0+; no custom fork required.
- [**macuse**](https://github.com/fitchmultz/macuse): native macOS app automation for Pi and MCP clients. **Experimental, unsupported integration** using ChatGPT's proprietary Computer Use runtime.

## Other work

- [**CueLoop**](https://github.com/fitchmultz/cueloop): queue and track coding-agent tasks, evidence, and handoffs.
- [**Spartan Scraper**](https://github.com/fitchmultz/spartan-scraper): scrape, crawl, and research websites through a UI, CLI, or API.
- [**agent-eval**](https://github.com/fitchmultz/agent-eval): inspect and compare local coding-agent transcripts.
- [**Cloop**](https://github.com/fitchmultz/cloop#how-it-works): local tasks and searchable knowledge, with a web UI and CLI.
- [**AI Control Plane**](https://github.com/fitchmultz/ai-control-plane): a reference implementation for AI governance, not a managed production service.
